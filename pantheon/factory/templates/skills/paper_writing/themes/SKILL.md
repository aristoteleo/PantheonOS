# Theme Skills

Use a theme only after the format contract is selected.

| Theme | Contract | Stylesheet | Default use |
|---|---|---|---|
| `kami_academic` | [kami_academic.md](./kami_academic.md) | [kami_academic.css](./kami_academic.css) | warm academic reports and editable paper previews |

The contract file (`.md`) defines theme rules and minimal CSS hooks; the
stylesheet file (`.css`) is the full drop-in implementation. Use the contract
when adapting or porting to another stylesheet, and the stylesheet when
applying the theme to an HTML output directly.

Do not let theme choices alter scientific claims or evidence checks.
