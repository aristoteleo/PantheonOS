Planner contract
Pure helper pantheon/evolution/methods/decision_prompt.py takes
build_decision_planner_prompt(native_prompt,eligible_anchor_ids,memory='')->str.
It edits the actual native rendered JSON example to include the explicit nullable
evidence_request field on EVERY direction, then asks >=1 concrete question per
portfolio when eligible BASE/ESTABLISHED live anchors exist. A request names an
exacteligibleanchor, mechanism, decision_to_inform,predicted_contrast,falsifier,
expected_cost={candidate_evaluations:2,template_model_calls:1}. Null is explicit
for directions with no useful question. The original required-redesign portfolio
remains intact; a question is not a new fourth architecture type or a completed
measurement. No algorithm/task-specific move is hardcoded.

Malformed planner replies retain predecessor safe-empty handling. Contract failures
are recorded, not repaired by fabricated questions or automatic paid retries.
Valid native architecture directions still run even when instrumentation fails.
Only native validated/dedup-kept directions own requests; actual native child and
context/source SHA are required before a diagnostic is dispatched.

Scheduling change
After initial native cohort drains (no pending/open_dirs), an established/base
anchor can receive a residual paired probe while OTHER sprouts are on probation.
The probed anchor must not itself belong to any active probationary chain.
Due native planning has priority whenever native Molt would actually permit it;
max_sprouts-blocked planning cannot indefinitely block a residual instrument.
One native batch receives priority when capacity permits, and only one probe can
be open. Native attempt/probation clocks never age twice from OFF/ON feedback.
Hard80candidate-slot cap (including seed/pending/failure reservations), <=8probe
slots/at least72native capacity, modelcall ceiling4diagnostic calls and inherited
financial/headroom rules remain. Unused allowance returns to native work.
$.05diagnostic spend is an observed/conservative gate, not a guaranteed pre-call
price ceiling. Ordinary SDK calls retain the caller's shared40USD reservation guard.

Observed OFF/ON differences remain conditional template contrasts; literal source
symmetry and aggregate anchor agreement do not prove semantic isolation or universal
causality. No repetitions/randomized order are newly introduced. Old component
memory cannot cross a full-redesign structural boundary merely by shared lineage.
Raw evidence and complete source states remain archived; prompt projection is bounded.
