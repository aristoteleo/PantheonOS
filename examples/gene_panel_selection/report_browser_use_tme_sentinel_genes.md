# Web research report: TME sentinel genes

Summary
- Goal: Provide concise, citable summaries and authoritative references for 20 sentinel genes in the human tumor microenvironment (TME).
- Sources prioritized: GeneCards, UniProt, NCBI Gene/Bookshelf, GO, and recent reviews.
- Constraint: The web search tool was unavailable (duckduckgo_search backend missing), so I compiled authoritative, stable database links that are deterministic (GeneCards canonical gene pages and UniProt organism-filtered query URLs). These resolve to human gene records and are widely used for annotation and citation.

Method
1. Drafted 1–2 line functional roles for each gene in TME context (lineage, effector, checkpoint, stroma/ECM, angiogenesis, proliferation).
2. Selected 1–2 authoritative references per gene (GeneCards + UniProtKB human filtered search URL).
3. Provided a compact list below and recorded all links; see references_1.bib for BibTeX entries.
