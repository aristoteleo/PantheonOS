# Settings

Manage workspace, model and connection settings from the desktop.

## Using this App

Open **Settings** to inspect and change the settings available for the current workspace. Model choices and connection options reflect the services configured for that workspace.

These settings affect the connected Pantheon environment. They do not change the local computer’s operating-system preferences. Use Fleet to add or inspect another compute node, and Store to manage App installations and versions.

## Package and source

This is a system App bundled with Pantheon. Its identity, capabilities and entry points are declared in [app.json](app.json). Updates ship with the Pantheon runtime.

The frontend is supplied by the desktop UI bundle; this directory declares its App integration.
