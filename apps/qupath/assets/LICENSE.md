# QuPath icon

`qupath.png` is the original QuPath 256-pixel application icon from the
[QuPath v0.7.0 source tree](https://github.com/qupath/qupath/blob/v0.7.0/qupath-gui-fx/src/main/resources/icons/QuPath_256.png).

[GPL-3.0](https://github.com/qupath/qupath/blob/v0.7.0/LICENSE).
The icon identifies the QuPath application embedded in Atrium.
